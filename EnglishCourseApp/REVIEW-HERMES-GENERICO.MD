    Opção 3: github-pr-workflow — O que é e o que cobre
    
    Esta skill é um guia completo do ciclo de vida de um PR no GitHub — do branch ao merge. Ela ensina dois caminhos para cada etapa:
    1. Via gh CLI (mais simples, recomendado)
    2. Via git + curl/REST API (fallback sem gh)
    
    
    
    📦 O que a skill cobre (7 seções):
    
    Seção: 1. Branch Creation
    O que faz: Criar branch com naming convention (feat/, fix/, refactor/,
      etc.)
    Exemplo de comando: git checkout -b fix/login-redirect-bug
    ────────────────────────────────────────
    Seção: 2. Making Commits
    O que faz: Commits convencionais (feat:, fix:, refactor:, etc.)
    Exemplo de comando: git commit -m "fix: correct redirect URL..."
    ────────────────────────────────────────
    Seção: 3. Push + Create PR
    O que faz: Push da branch + abrir PR com título/body/reviewers/labels
    Exemplo de comando: gh pr create --title "..." --body "..."
    ────────────────────────────────────────
    Seção: 4. Monitoring CI
    O que faz: Ver status, watch até acabar, polling loop (curl)
    Exemplo de comando: gh pr checks --watch
    ────────────────────────────────────────
    Seção: 5. Auto-Fixing CI Failures
    O que faz: Loop: check CI → ler logs → fixar código → commit/push →
      re-check
    Exemplo de comando: gh run view <ID> --log-failed
    ────────────────────────────────────────
    Seção: 6. Merging
    O que faz: Squash/merge/rebase, auto-merge, deletar branch
    Exemplo de comando: gh pr merge --squash --delete-branch

    Seção: 7. Complete Example
